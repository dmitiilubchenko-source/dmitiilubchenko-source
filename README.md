# Hi, I'm Dmitriy

I build tools for numerical simulation, data collection and desktop workflows.
My main project is **Solar Simulator**, a gravitational laboratory built with Python and Rust.

**Python · Rust · NumPy · SciPy · Matplotlib · pytest · Git**

## Selected projects

### [Solar Simulator](https://github.com/dmitiilubchenko-source/Solar-Simulator)

A desktop N-body gravitational laboratory with a graphical interface and CLI.

- Python/SciPy integration with native Rust force calculations.
- Editable experiments, trajectories, checkpoints and recovery workflows.
- Reproducible validation against reference data, with documented numerical errors and model limitations.
- Portable Windows packaging and automated Python/Rust checks.

[User guide](https://github.com/dmitiilubchenko-source/Solar-Simulator/blob/main/docs/user-guide.md) · [Physics and validation](https://github.com/dmitiilubchenko-source/Solar-Simulator/blob/main/docs/physics.md)

### [Data collection projects](https://github.com/dmitiilubchenko-source/parsers-github)

Python pipelines for airport information, election protocols and retail prices.

- HTTP and browser-based collection with HTTPX and Selenium across the collection projects.
- Processing, completeness reports and small reproducible examples.
- Saved airport results cover **10,508 valid ICAO-coded records**; the election party-protocol table covers **91,381 polling stations**, including missing records.

[Run instructions](https://github.com/dmitiilubchenko-source/parsers-github/blob/main/README.md) · [Saved results and limitations](https://github.com/dmitiilubchenko-source/parsers-github/blob/main/%D0%9C%D0%98%D0%9D%D0%98_%D0%92%D0%AB%D0%92%D0%9E%D0%94%D0%AB.md)

### [AmneziaVPN Google Ping & Rank](https://github.com/dmitiilubchenko-source/amnezia-vpn-google-ping)

An independent, experimental Windows fork of AmneziaVPN with country benchmarking and connection diagnostics.

- Median/P95 latency, observed loss and RTT variation.
- Two-stage measurements, cancellation, progress and favorites.
- Build instructions, automated tests and release source archives.

The original AmneziaVPN application belongs to its upstream contributors. My fork's changes and GPL licensing are documented in the [fork notice](https://github.com/dmitiilubchenko-source/amnezia-vpn-google-ping/blob/codex/premium-latency/FORK-NOTICE.md).
